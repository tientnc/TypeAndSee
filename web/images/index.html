How this search worked

CLIP creates image and text embeddings. Orama compares vectors in this browser. The library is saved in IndexedDB on this device.

StepTime

Similarity measures closeness in embedding space. It is not a confidence score. This demo performs vector retrieval; generated explanations are available only in the separate Python app.

Photos you add stay in this browser. No sign-in, API key, or server inference.

The first search downloads the CLIP model. Imports also load its image encoder. Your browser can cache both.
